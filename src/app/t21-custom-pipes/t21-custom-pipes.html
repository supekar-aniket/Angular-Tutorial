Pipes and Custom Pipes in Angular:

    1. What are Pipes:
      • Pipes are used to transform data before displaying it in the view.
      • They do not change the original data.
      • Pipes are used only in HTML templates.
      • Pipes use the pipe ( | ) symbol.

    2. Why we use Pipes:
      • To format data easily in the template.
      • To keep HTML clean and readable.
      • To reuse formatting logic.
      • To avoid writing extra code in the component.

    3. Built-in Pipes in Angular:
      • date - formats date values.
      • uppercase - converts text to uppercase.
      • lowercase - converts text to lowercase.
      • titlecase - converts text to title case.
      • currency - formats number as currency.
      • percent - converts number to percentage.

    4. Pipe Syntax:
      • Pipes are applied using the | symbol.
      • Multiple pipes can be chained together.
      • Pipe arguments are passed using colon (:).

    5. What is a Custom Pipe:
      • Custom pipe is a user-defined pipe.
      • It is used when built-in pipes are not sufficient.
      • Custom pipes are created using Pipe decorator.
      • They contain a transform() method.

    6. Why we use Custom Pipes:
      • To apply custom formatting logic.
      • To reuse custom transformation logic.
      • To keep templates clean.
      • To follow separation of concerns.

    7. Steps to Create a Custom Pipe:
      1. Create Pipe
        • Use @Pipe decorator.
        • Provide a unique pipe name.
      2. Implement PipeTransform
        • Implement PipeTransform interface.
        • Define transform() method.
      3. Use Pipe in HTML
        • Apply pipe using | symbol.

    8. Example Custom Pipe Use Case:
      • Convert empty or null value to 'N/A'.
      • Format user name.
      • Custom text transformation.

    9. Advantages of Pipes:
      • Reusable and clean code.
      • Improves readability.
      • Easy to maintain.
      • Separates logic from template.

    10. One Line Summary:
      • Pipes transform data in Angular templates, and custom pipes allow developers to define their own data transformations.
